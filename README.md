## 🚀 Quick Start (Devnet)

ปัจจุบันระบบรันอยู่บน **Private Devnet** พร้อมพอร์ตเชื่อมต่อ RPC สำหรับนักพัฒนา

### ⛓️ Network Specifications
- **Network Name:** UHU Pulse Devnet
- **RPC URL:** `https://rpc.uhu-layer2.com`
- **Chain ID:** `1337`
- **Currency Symbol:** `UHU`
- **Genesis Allocation:** 10,000,000,000 UHU ✅

### 🛠️ Run your own Node
```bash
# 1. Clone repo
git clone [https://github.com/uhulayer2-svg/uhu-l1.git](https://github.com/uhulayer2-svg/uhu-l1.git)
cd uhu-l1

# 2. คัดลอก Config และรันโหนด (Reth Engine)
cd node
reth node --chain ./genesis.json --http --http.api all

✨ Features หลัก
⚡ 10ms Block Time: ประสิทธิภาพสูงสุดด้วย Reth + Custom Execution Extensions (ExEx).

🧠 Neural Pulse AI: ระบบ AI On-chain สำหรับ Real-time anomaly detection และการตรวจสอบ Compliance อัตโนมัติ.

📜 Full ERC-3643 Suite: รองรับมาตรฐาน T-REX (Tokenization + Identity + Compliance) ในระดับโปรโตคอล.

🏢 Sovereign RWA Focus: ปรับแต่งมาเพื่อการทำ Tokenization ของอสังหาริมทรัพย์, หุ้น, และกองทุนโดยเฉพาะ.
